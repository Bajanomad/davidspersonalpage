# David's Personal Page

David's personal landing page: the glyph wheel. Black screen, green glyph rain, symbol doors, no text anywhere. His signature page from his old personal site, rebuilt as its own repo.

## How it works

- index.html is the whole page: one self-contained file with the glyph artwork embedded in it.
- On load: black screen, the center pyramid symbol fades in, the glyph rain starts, then the doors fade in one by one clockwise from the top, then everything flashes a couple of times.
- Doors point at the live 411 Matrix sections for now. Center goes to the 411 home page. Clockwise from the top: arcade, weather, news, Section 13 on Facebook, market, map.
- Hosted on GitHub Pages from the main branch root: https://bajanomad.github.io/davidspersonalpage/
- The same wheel is also the front door of 411matrix (411matrix.vercel.app). Icon and share image files load from the 411 site so this repo stays one file.
